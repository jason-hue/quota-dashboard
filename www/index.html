关于凭证

支持三种形式：平台控制台创建的 API Key、带 Bearer 前缀的令牌、以及从浏览器复制的登录令牌（eyJ 开头）。智谱新版积分套餐还需在编辑里补上组织 ID 和项目 ID。

所有凭证只保存在当前浏览器的本地存储中。应用是纯静态页面，直接向服务商查询，不经过任何中间服务器。

备份凭证（重要）

DeepSeek 的 Key 只在创建时显示一次。建议导出备份存到备忘录或网盘，清除数据后可一键恢复，无需重新创建 Key。

自动导入：复制备份文本后打开 App（或切回前台），会自动识别并恢复。当前无账号时直接恢复；已有账号时会先询问并合并。
